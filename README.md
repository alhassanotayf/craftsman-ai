# Craftsman AI

تطبيق ويب مدعوم بالذكاء الاصطناعي يساعد المستخدم على وصف مشكلة فنية باللغة الطبيعية، ثم يقوم تلقائيًا بتحديد التخصص المناسب والأولوية، مع إمكانية تعديل النتيجة قبل حفظ الطلب.

## المميزات

- تحليل المشاكل باستخدام Google Gemini API.
- تصنيف المشكلة إلى:
  - Plumbing
  - Electrical
  - Carpentry
  - AC
  - Insulation
  - Flooring
  - Other
- تحديد الأولوية:
  - Normal
  - Urgent
- عرض نسبة الثقة في نتيجة الذكاء الاصطناعي.
- إمكانية تعديل التصنيف والأولوية يدويًا قبل الحفظ.
- تقسيم الطلب الذي يحتوي على أكثر من مشكلة إلى طلبات منفصلة.
- حفظ الطلبات باستخدام ملف JSON.
- صفحة Requests لعرض جميع الطلبات مع المشكلة والتصنيف والأولوية والتاريخ.
- دعم اللغة العربية والإنجليزية.
- تصميم Responsive مناسب للكمبيوتر والجوال.

## التقنيات المستخدمة

- Next.js
- React
- TypeScript
- Tailwind CSS
- Next.js API Routes
- Google Gemini API
- JSON Storage
- Node.js
- Git / GitHub

## طريقة عمل النظام

المستخدم يكتب المشكلة في الواجهة، ثم يتم إرسالها إلى:

`POST /api/classify`

بعد ذلك يقوم Backend باستدعاء Gemini API وتحليل المشكلة، ثم يعيد:

- Description
- Category
- Priority
- Confidence

بعد ظهور النتيجة يستطيع المستخدم تعديل التصنيف أو الأولوية، ثم حفظ الطلب.

## الذكاء الاصطناعي

تم استخدام Google Gemini كخدمة الذكاء الاصطناعي الأساسية لتصنيف المشاكل.

مثال:

`المكيف لا يبرد في غرفة النوم`

النتيجة المتوقعة:

`Category: AC`

`Priority: Normal`

وفي حالة وجود أكثر من مشكلة:

`عندي تسريب مياه في المطبخ والكهرباء مقطوعة في غرفة النوم`

يمكن للنظام فصلها إلى مشكلتين مستقلتين، ولكل مشكلة تصنيف وأولوية خاصة بها.

## حماية API Key

يتم استخدام Gemini API من جانب الخادم من خلال Next.js API Route، ولا يتم وضع المفتاح داخل كود الواجهة الأمامية.

يتم تعريف المفتاح من خلال:

`GEMINI_API_KEY`

في ملف `.env.local`.

## تشغيل المشروع محليًا

تأكد من تثبيت Node.js وnpm.

ثم قم بتثبيت الحزم:

```bash
npm install
```

شغل المشروع باستخدام:

```bash
npm run dev
```

سيظهر رابط مشابه لـ:

`http://localhost:3000`

إذا كان الكمبيوتر والجوال متصلين بنفس شبكة Wi-Fi، يمكن تشغيل المشروع ليكون متاحًا من الجوال.

شغل:

```bash
npm run dev -- -H 0.0.0.0
```

بعدها:

```bash
ipconfig
```

ابحث عن:

`IPv4 Address`

مثلًا:

`192.168.1.10`

بعدها افتح من الجوال:

`http://192.168.1.10:3000`
